## 2. QUÉ SE RESTAURA

Desde el padre `c6655fce13b99bf9aeedc8a2582ae7651d0e73e6`:

### F2 — planilla identical proof upload failure preserves existing proof

```php
it('F2: planilla identical proof upload failure preserves existing proof', ...)
```

Prueba mínima para `PlanillaFileStore`: subida exitosa A → segunda subida con
bytes idénticos → fallo de metadato B tras escritura de archivo → excepción
propaga → fila A existe → archivo A existe → bytes inalterados → sin huérfano B.

### F3 — portal outer transaction rollback removes only the newly written file

```php
it('F3: portal outer transaction rollback removes only the newly written file', ...)
```

Prueba real `RespondToDocumentRequest`: documento A subido → request rechazado
→ cliente sube reemplazo B → `DocumentFileStore` tiene éxito para B → fallo
determinista tras file store dentro de la transacción de negocio →
compensación exterior `catch` en `RespondToDocumentRequest` → BD hace rollback
→ request sigue `Rejected` → solo fila documento A queda → archivo físico A
existe → archivo B eliminado.

F3 **ejercita la implementación actual R3** de compensación exterior (el `catch`
que envuelve `DB::transaction`).
